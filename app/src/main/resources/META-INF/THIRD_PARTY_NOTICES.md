## Functional inspiration

The MIUI countdown feature was reconstructed with reference to the behavior
and APK analysis of BetterMIUI 1.5 (`com.mikutart.bettermiui`).
This repository contains the separately written modern module, not recovered
upstream sources, the original APK, or its assets. The original also supported
ColorOS; this module implements the Xiaomi functionality only.
